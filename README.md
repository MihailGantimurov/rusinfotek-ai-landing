# РусИнфоТек — AI-автоматизация бизнеса

Премиальный адаптивный B2B-лендинг компании «РусИнфоТек». Сайт представляет модульные AI-решения для автоматизации продаж, логистики, производства и документооборота.

## Сайт

[rusinfotek-ai-automation.apocritonsapeiens.chatgpt.site](https://rusinfotek-ai-automation.apocritonsapeiens.chatgpt.site/)

## Технологии

- Next.js / React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- Vinext / Cloudflare Workers

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```

## Дизайн-система

- Oxford Blue: `#002147`
- Бирюзовый акцент: `#00FFE8`
- Строгая тёмная тема
- Адаптивная mobile-first вёрстка
- Кинетическая типографика, продуктовая телеметрия и микроанимации

## Структура

- Первый экран с маршрутом «заявка → оплата»
- Метрики и подтверждённые результаты
- Модульная продуктовая архитектура
- Кейсы внедрения
- Enterprise-безопасность
- Двухнедельный процесс запуска
- Форма запроса аудита

## Архитектура проекта

- `app/` — маршруты главной и будущих разделов корпоративного сайта
- `components/layout/` — шапка, подвал и элементы фирменного layout
- `components/shared/` — переиспользуемые анимационные и секционные компоненты
- `components/home/` — секции текущей главной страницы
- `content/` — статические данные, используемые страницами
- `components/ui/` — существующая библиотека UI-компонентов
